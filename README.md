# FPGA Digital Clock

## Overview

Designed and implemented a physical digital clock on FPGA hardware using Verilog. The project involved developing the digital logic required for accurate timekeeping and integrating the design into a working hardware implementation.

Through this project, I gained practical experience with RTL design, FPGA development, digital logic, and hardware debugging.

## Key Features

- Digital clock implemented in Verilog
- FPGA-based hardware implementation
- Timekeeping logic for hours, minutes, and seconds
- Modular RTL design
- Hardware testing and debugging
- Integration of digital logic with physical FPGA hardware

## Technologies

- Verilog
- FPGA
- RTL Design
- Digital Logic
- Hardware Development

## Skills Developed

This project strengthened my understanding of:

- Sequential and combinational logic
- Clock-driven digital systems
- Counters and finite-state logic
- RTL design principles
- FPGA synthesis and implementation
- Hardware-level debugging and validation
